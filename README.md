# Library Management System

A simple Library Management System developed using Flask, SQLite, HTML, CSS and JavaScript.

## Features

- Admin Login
- Student Registration
- Student Management
- Add and Edit Books
- Book Management
- Issue Books
- Return Books
- Maximum 3 Books per Student
- Explore Books
- Take Book using Enrollment Number
- Complete Book Details
- Search Students
- Book Availability Tracking

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
